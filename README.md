# 蛋仔单词本 · Eggy Vocab

基于 **艾宾浩斯遗忘曲线** 的单词记忆 App。纯前端、**多平台网页可访问**、可跨设备同步。

## 怎么用

1. **启动**（任选其一）：
   - 双击 `index.html` 直接用浏览器打开
   - 或跑本地服务：`python -m http.server 8080` → 打开 http://localhost:8080
2. **加词**：在「单词」页输入英文 + 中文 → 回车。支持批量粘贴。
3. **复习**：点「开始复习」，答对升 1 级、答错降 2 级。完成 30 天后的最终复习才毕业 🎓
4. **同步**：推荐使用设置页的「房间码云同步」；多台设备输入同一房间码即可合并。每次复习结束会自动上传，重新打开网页会自动拉取。GitHub Gist 可作为备用同步方式。

## 艾宾浩斯曲线（9 级）

| 次数 | 间隔 | 说明 |
|------|------|------|
| 第1次 | 5 分钟 | 刚学完，马上考 |
| 第2次 | 30 分钟 | 短时巩固 |
| 第3次 | 12 小时 | 睡前再想一遍 |
| 第4次 | 1 天 | 次日回顾 |
| 第5次 | 2 天 | 隔天再认 |
| 第6次 | 4 天 | 四天后巩固 |
| 第7次 | 7 天 | 一周关键节点 |
| 第8次 | 15 天 | 半月巩固 |
| 第9次 | 30 天 | 长期记忆 |
| 30 天后答对 | 🎓 | 毕业 |

答错会**倒退 2 级并 30 秒后立刻重来**。跨设备同步时，同一个词以最近一次真实作答为准，避免旧设备覆盖较新的遗忘记录。

## 同步与备份注意事项

- 房间码相当于同步凭证：只分享给需要同步的设备，并自行保存；新创建的房间使用长随机码。
- JSON 导出包含完整学习数据和房间码，但**不包含 GitHub Token**。在新设备使用 Gist 同步时，需要手动重新填写 Token。
- 同时在两台设备复习同一个词时，后一次作答会成为该词的最新进度；建议复习结束后等待自动上传完成再切换设备。


## Lesson 4「まいにち / Everyday Life」

词库文件 `seed-lesson4.js`（94 词，对应《Adventures in Japanese 1》第 4 版 4か1〜4か5），
含读音、汉字、中文、课本风格英文与配套例句。中文释义与例句为配套编写，非课本原文。

- `index.html` 在 `app.js` 之前加载本文件，并置 `window.EGGY_MERGE_LESSON4 = true`，
  词条会合并进 `SEED_WORDS`，`SEED_RANK` 自动把 L4 排在 Lesson 3 之后，符合课本顺序。
- 默认开启，但**每天只解锁 8 个新词**（设置页可调 1–30），未解锁的词不会进入待复习队列，
  避免一次塞 94 词把首页撑爆。已开始学习的词不受开关影响。
- 设置页「课本进度 · Lesson 4」可开关词库、调整每日解锁数，并查看解锁进度。
- 新增词字段 `deck: "L4"` / `unlockDay`，已纳入房间码同步合并，跨设备不会重复解锁。
- 这批词**暂无真人配音**，会自动回退到设备自带日语 TTS（iPad / Edge 可用）。

生成脚本与分单元 CSV 见 `egg-vocab-lesson4/`（本地工作区，未纳入本仓库）。
