# 蛋仔单词本 · Eggy Vocab

基于 **艾宾浩斯遗忘曲线** 的单词记忆 App。纯前端、**多平台网页可访问**、可跨设备同步。

## 怎么用

1. **启动**（任选其一）：
   - 双击 `index.html` 直接用浏览器打开
   - 或跑本地服务：`python -m http.server 8080` → 打开 http://localhost:8080
2. **加词**：在「单词」页输入英文 + 中文 → 回车。支持批量粘贴。
3. **复习**：点「开始复习」，答对升 1 级、答错降 2 级。完成 30 天后的最终复习才毕业 🎓
4. **同步**：推荐使用设置页的「房间码云同步」；多台设备输入同一房间码即可合并。每次复习结束会自动上传，重新打开网页会自动拉取。GitHub Gist 可作为备用同步方式。

## 艾宾浩斯曲线（9 级）

| 次数 | 间隔 | 说明 |
|------|------|------|
| 第1次 | 5 分钟 | 刚学完，马上考 |
| 第2次 | 30 分钟 | 短时巩固 |
| 第3次 | 12 小时 | 睡前再想一遍 |
| 第4次 | 1 天 | 次日回顾 |
| 第5次 | 2 天 | 隔天再认 |
| 第6次 | 4 天 | 四天后巩固 |
| 第7次 | 7 天 | 一周关键节点 |
| 第8次 | 15 天 | 半月巩固 |
| 第9次 | 30 天 | 长期记忆 |
| 30 天后答对 | 🎓 | 毕业 |

答错会**倒退 2 级并 30 秒后立刻重来**。跨设备同步时，同一个词以最近一次真实作答为准，避免旧设备覆盖较新的遗忘记录。

## 特性

- 🥚 蛋仔可爱风格，移动优先
- 📱 手机 / 平板 / PC 任何现代浏览器可跑
- 🧠 艾宾浩斯遗忘曲线驱动
- 🔊 内置 TTS 朗读（英语真人发音）
- 📚 内置 90+ 常见词真实例句（离线可用）

- 📤 导出/导入 JSON + CSV
- 🌐 可选联网翻译（MyMemory）+ 例句补全（Tatoeba）

## 同步与备份注意事项

- 房间码相当于同步凭证：只分享给需要同步的设备，并自行保存；新创建的房间使用长随机码。
- JSON 导出包含完整学习数据和房间码，但**不包含 GitHub Token**。在新设备使用 Gist 同步时，需要手动重新填写 Token。
- 同时在两台设备复习同一个词时，后一次作答会成为该词的最新进度；建议复习结束后等待自动上传完成再切换设备。
